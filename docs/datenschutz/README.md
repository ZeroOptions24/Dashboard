# Datenschutz – Entwürfe als Vorlage für Anwalt / Datenschutzbeauftragten

**Keine Rechtsberatung.** Diese Unterlagen beschreiben technisch, welche Daten das MB-Dashboard wo und wofür verarbeitet. Sie sind Arbeitsgrundlage für die rechtliche Formulierung, nicht deren Ersatz. Stellen mit **[PRÜFEN]** muss der Anwalt bzw. DSB entscheiden.

| --- | --- |

| [vvt-eintraege.md](vvt-eintraege.md) | Entwurf der Einträge im Verzeichnis von Verarbeitungstätigkeiten (Art. 30 DSGVO) |
| [haustuer-kundeninfo.md](haustuer-kundeninfo.md) | Fakten + Formulierungsvorschlag für die Information der Kunden an der Haustür |

**Ablage der AV-Verträge** (Strato, Pipedrive, n8n, Yousign, E-Mail-Anbieter): im Datenschutz-Ordner eurer Firmenablage, je Dienst ein PDF mit Datum; im VVT beim jeweiligen Empfänger darauf verweisen.
